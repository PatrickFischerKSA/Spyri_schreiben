# Spyri200 Schreibwerkstatt

[Website öffnen](https://patrickfischerksa.github.io/Spyri_schreiben/)

Die Gruppen entwickeln aus ihren jeweiligen [Spyri200-Projekten](https://spyri-200-ausstellung.patrickoliverfischer.chatgpt.site/), Leitfragen und gelesenen Texten eine neue Erzählung. Vorgesehen sind drei Lektionen, 700–900 Wörter, höchstens drei Szenen, drei belegte Erkenntnisse, ein Werkkommentar und dokumentierte Überarbeitungen.

## Benutzung
Erkenntnisbogen ausfüllen, Handlung planen und selbst schreiben oder den erzeugten Prompt manuell in ChatGPT kopieren. Anschliessend gemeinsam prüfen, überarbeiten und kommentieren. Der Arbeitsweg ohne KI ist gleichwertig. Der gesamte Arbeitsprozess findet auf der Website statt: erster Entwurf, Rückmeldung, drei begründete Änderungen, Endfassung und Werkkommentar haben eigene Eingabefelder. Wortzähler und eine Vollständigkeitsprüfung unterstützen den Abschluss. Eine Textdatei exportiert die gesamte Arbeit für die Abgabe.

Eingaben bleiben lokal im Browser. JSON-Export und -Import sichern alle Eingaben. Ältere Notizdateien können weiterhin geladen werden. Der Kopierknopf bietet bei blockierter Zwischenablage einen manuellen Ersatzweg.

## Technik
Statisches HTML, CSS und JavaScript ohne Backend oder API. Die Seite überträgt keine Schülertexte und ruft keine KI auf. GitHub Pages veröffentlicht den Stammordner des Branches `main`. Alle Website-Dateien liegen im Repository-Stamm.
